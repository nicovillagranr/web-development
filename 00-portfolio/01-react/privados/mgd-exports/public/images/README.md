# Imágenes del Sitio

Este directorio contiene las imágenes utilizadas en el landing page de MGD Exports.

## Archivos Requeridos

### hero-bg.jpg
- **Ubicación**: `public/images/hero-bg.jpg`
- **Uso**: Imagen de fondo del hero (sección principal)
- **Dimensiones recomendadas**: 1920x1080px o mayor (16:9 aspect ratio)
- **Descripción**: Imagen relacionada con minería, industria pesada o equipamiento industrial
- **Sugerencias**: 
  - Maquinaria minera en operación
  - Trabajadores con EPP en sitio de trabajo
  - Equipamiento industrial profesional
  - Entorno minero/industrial de día

### logo.png
- **Ubicación**: `public/images/logo.png`
- **Uso**: Logo de la empresa en la navbar y footer
- **Dimensiones recomendadas**: 200x50px minimum
- **Formato**: PNG con transparencia (recomendado)
- **Descripción**: Logo de MGD Exports

### about-team.jpg
- **Ubicación**: `public/images/about-team.jpg`
- **Uso**: Imagen en la sección "Sobre Nosotros"
- **Dimensiones recomendadas**: 500x500px (cuadrado)
- **Descripción**: Foto del equipo o instalaciones de la empresa
- **Sugerencias**:
  - Equipo profesional de MGD Exports
  - Instalaciones/oficinas
  - Centro de almacenamiento
  - Evento corporativo

## Cómo Reemplazar las Imágenes

1. Prepara tus imágenes en las dimensiones recomendadas
2. Reemplaza los archivos en este directorio
3. Recarga el navegador (Ctrl+F5 para limpiar cache)
4. Asegúrate de que la calidad sea adecuada para web

## Formatos Soportados

- JPEG (.jpg, .jpeg) - Para fotos
- PNG (.png) - Para imágenes con transparencia o logos
- WebP (.webp) - Para mejor compresión

## Optimización Recomendada

Para mejor performance:
- Usa herramientas como TinyPNG, ImageOptim o Squoosh
- Convierte a WebP donde sea posible
- Mantén el tamaño de archivo < 500KB por imagen
