# Claude Code - Modulo de aprendizaje

Este modulo centraliza el aprendizaje de Claude Code: la CLI oficial de Anthropic para trabajar con IA directamente desde la terminal.

## Estructura

- `00-fundamentals/`: que es Claude Code, instalacion y primeros pasos.
- `01-comandos/`: comandos slash, atajos de teclado y modos de uso.
- `02-agentes/`: como funcionan los agentes y cuando usarlos.
- `03-skills/`: skills disponibles y como sacarles partido.
- `04-hooks/`: configuracion de hooks para automatizar acciones.
- `05-cheatsheets/`: referencia rapida por escenario.

## Objetivo

Dominar Claude Code como herramienta de desarrollo profesional: desde el uso basico hasta la automatizacion con agentes, hooks y skills.

## Indice recomendado de estudio

1. `00-fundamentals/que-es-claude-code.md`
2. `01-comandos/comandos-slash.md`
3. `02-agentes/guia-agentes.md`
4. `03-skills/guia-skills.md`
5. `04-hooks/guia-hooks.md`
6. `05-cheatsheets/claude-code-cheatsheet.md`
