# Git Learning Module

Este modulo centraliza el aprendizaje de Git y el flujo de trabajo con GitHub.

## Estructura real

- `00-fundamentals/`: base conceptual de control de versiones.
- `01-commits/`: convenciones de commits y guia practica.
- `02-branching/`: estrategias de ramas.
- `03-github/`: flujo remoto y colaboracion.
- `04-cheatsheets/`: referencia rapida de comandos.

## Estado actual

- `00-fundamentals/`: guia base de Git y flujo local.
- `01-commits/`: convenciones de commits y guia practica.
- `02-branching/`: guia de ramas, merge/rebase y conflictos.
- `03-github/`: flujo remoto, PRs, forks y releases.
- `04-cheatsheets/`: referencia rapida y troubleshooting.

## Objetivo

Tener una base de Git clara, reproducible y orientada a trabajo profesional.
