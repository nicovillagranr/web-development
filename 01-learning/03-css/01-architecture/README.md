# 01-architecture

Base de arquitectura CSS para construir codigo mantenible.

## Estructura

- `01-learning-layers/`: progresion conceptual por niveles.
- `02-css-documentation/`: referencia tecnica (reset, variables, layout, components, utilities, selectors).

## Resultado esperado

Al terminar este bloque deberias poder:

- justificar decisiones de arquitectura CSS
- separar estilos por responsabilidad
- escribir clases consistentes y escalables
- evitar acoplamientos fragiles en selectores

## Orden sugerido

1. Leer `01-learning-layers/01-fundations.md` a `05-advanced.md`.
2. Revisar `02-css-documentation/` archivo por archivo.
3. Aplicar la arquitectura en un proyecto real de `02-layouts`.
