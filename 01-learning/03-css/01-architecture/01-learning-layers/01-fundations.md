# Layer 01: Fundations

## Objetivo

Entender la base de CSS antes de entrar a sistemas complejos.

## Conceptos clave

- cascada
- especificidad
- herencia
- box model
- flujo normal del documento

## Practica minima

1. Crear un documento simple con `header`, `main`, `footer`.
2. Aplicar reset minimo.
3. Definir tipografia base y escala de espaciados.
4. Validar que el layout sea legible sin hacks.

## Checklist

- [ ] diferencias claras entre `margin`, `padding` y `border`
- [ ] comprension de prioridad entre selector, orden y `!important`
- [ ] uso de unidades relativo al contexto (`rem`, `%`, `vw`)
