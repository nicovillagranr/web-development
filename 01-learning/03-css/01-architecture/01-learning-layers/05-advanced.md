# Layer 05: Advanced

## Objetivo

Aplicar tecnicas avanzadas con criterio, no por moda.

## Temas

- container queries
- subgrid
- capas de cascade (`@layer`)
- funciones modernas (`clamp`, `min`, `max`)
- performance de render y animaciones

## Practica minima

1. Ajustar tipografia con `clamp`.
2. Implementar layout adaptativo con `minmax` y `auto-fit`.
3. Crear animacion suave respetando `prefers-reduced-motion`.
4. Revisar costo de reglas en componentes complejos.

## Checklist

- [ ] cada tecnica avanzada resuelve un problema concreto
- [ ] accesibilidad respetada en interacciones y movimiento
- [ ] performance visual estable en equipos medios
