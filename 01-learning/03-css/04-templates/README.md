# 04-templates

Laboratorio de maquetacion CSS basado en referencias visuales.

## Objetivo

Convertir referencias graficas en interfaces funcionales, empezando por un MVP limpio y escalable.

## Regla de trabajo por template

Cada carpeta `template-*` contiene:

- `brief.md`: objetivo, alcance y checklist.
- `index.html`: estructura semantica minima.
- `style.css`: base visual responsive.

## Enfoque

- implementar primero estructura y jerarquia
- despues ajustar espaciado, tipografia y color
- por ultimo refinar detalles visuales

## Resultado esperado

Al cerrar un template debes poder explicar:

- como tradujiste la referencia a estructura HTML
- por que elegiste ese layout CSS
- que quedo fuera del MVP y que seria siguiente iteracion
