# CSS Module

Este modulo cubre maquetacion y estilos web desde base hasta proyectos aplicados.

## Estructura real

- `00-assets/`: recursos comunes (fuentes, iconos, imagenes y librerias).
- `01-architecture/`: capas de aprendizaje y documentacion de arquitectura CSS.
- `02-layouts/`: teoria y practica de flexbox, grid y responsive.
- `03-frameworks/`: practica de Bootstrap y Tailwind con proyectos reales.
- `04-templates/`: laboratorio de maquetacion basado en referencias visuales.

## Estado actual

- Bootstrap: evidencia tecnica agregada con ejemplos de grid y componentes.
- Tailwind: implementacion aplicada en proyectos completos.
- Arquitectura: learning layers completos desde base a avanzado.
- Templates: estructura MVP para practicar maquetacion con CSS puro.

## Metodologia

- convencion de nombres consistente
- enfoque modular
- prioridad en legibilidad y escalabilidad
- practica incremental con ejercicios y checklist
