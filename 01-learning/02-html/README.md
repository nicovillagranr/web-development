# 02-html Learning Module

Modulo de practica progresiva para dominar HTML semantico y accesible.

## Estructura

- `00-overview/`: vision general del modulo.
- `01-intro/`: fundamentos iniciales.
- `02-projects/`: 25 proyectos practicos.
- `03-guides/`: guias de estudio por bloque.

## Ruta recomendada

1. Leer `00-overview/00-readme.md`.
2. Revisar `01-intro/README.md`.
3. Completar `02-projects/01` a `25` en orden.
4. Usar `03-guides/` para reforzar conceptos.

## Criterio de dominio

- Estructuras contenido sin depender de estilos.
- Usas etiquetas segun significado, no por apariencia.
- Validas accesibilidad base en cada pagina.
- Puedes explicar por que cada etiqueta existe.
