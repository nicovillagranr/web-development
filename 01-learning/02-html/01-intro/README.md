# HTML Intro

Este modulo concentra fundamentos de HTML con enfoque practico.

## Objetivo

Construir documentos semanticos, accesibles y mantenibles antes de pasar a CSS y JS.

## Checklist tecnico

- Estructura base de documento (`<!doctype html>`, `html`, `head`, `body`)
- Jerarquia correcta de titulos (`h1` a `h6`)
- Semantica estructural (`header`, `main`, `section`, `article`, `footer`)
- Formularios con etiquetas y atributos de accesibilidad
- Navegacion con enlaces internos y externos

## Resultado esperado

Al terminar este bloque, puedes justificar por que cada etiqueta existe y no solo "hacer que se vea bien".
