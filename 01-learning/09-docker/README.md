# Docker Learning Module

Este modulo centraliza el aprendizaje de Docker con enfoque practico.

## Estructura real

- `00-fundamentals/`: base conceptual de Docker y ciclo de trabajo.
- `01-images/`: construccion, etiquetado y publicacion de imagenes.
- `02-containers/`: ejecucion, depuracion y operacion de contenedores.
- `03-compose/`: orquestacion local de multiples servicios.
- `04-cheatsheets/`: referencia rapida y troubleshooting.

## Estado actual

- `00-fundamentals/`: guia base de arquitectura Docker y comandos iniciales.
- `01-images/`: guia de Dockerfile, build, tags y optimizacion.
- `02-containers/`: guia de runtime, logs, exec, volumenes y redes.
- `03-compose/`: flujo de trabajo con `docker compose` para entornos locales.
- `04-cheatsheets/`: comandos clave y soluciones a errores comunes.

## Objetivo

Tener una base de Docker clara, reproducible y orientada a desarrollo profesional.
