# React Learning Path ⚛️

Este módulo documenta mi proceso de aprendizaje en **React.js**, desde los fundamentos hasta proyectos completos e integraciones con librerías avanzadas como **Three.js**.  
Cada carpeta representa una etapa progresiva, enfocada en comprender el flujo de trabajo real en desarrollo Front-End moderno.

---

## 🧩 Estructura del repositorio


---

## 📘 01-basics  
Ejercicios iniciales de React: componentes funcionales, props, estado, eventos y renderizado condicional.  
Aquí construyo la base conceptual antes de escalar a proyectos.

---

## ⚙️ 02-hooks  
Exploración práctica de los hooks principales (`useState`, `useEffect`, `useRef`, `useMemo`, `useReducer`) y creación de hooks personalizados.  
Me enfoco en la composición lógica y la reutilización de código.

---

## 🧭 03-router  
Implementación de **React Router** para manejar navegación, rutas dinámicas y layouts anidados.  
Objetivo: entender cómo estructurar una SPA (Single Page Application) escalable.

---

## 🌐 04-context  
Gestión de estado global con Context API y patrones de provider/consumer.  
Aquí aprendo a evitar el “prop drilling” y mantener la app organizada.

---

## 🚀 05-projects  
Aplicaciones completas que integran lo aprendido: CRUDs, to-do lists, paneles de control, landing pages interactivas, etc.  
También incluyo prácticas de rendimiento, estructura de carpetas y patrones de diseño.

---

## 🪄 06-threejs  
Integraciones de **React + Three.js** para interfaces 3D, animaciones y escenas interactivas.  
Este módulo se centra en el desarrollo visual y en la experimentación con **react-three-fiber**.

---

## 🧠 Filosofía de aprendizaje  
Cada ejercicio sigue tres principios:
1. **Comprensión antes que automatización**: entender la lógica detrás de cada concepto.  
2. **Escalabilidad**: escribir código que pueda crecer, no solo funcionar.  
3. **Consistencia**: mantener buenas prácticas desde los fundamentos.

---

## 🛠️ Stack de práctica
- React 18+
- Vite
- React Router DOM
- Context API
- Three.js / React Three Fiber
- CSS Modules / TailwindCSS
