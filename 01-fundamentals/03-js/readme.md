# 🧠 JavaScript Logic

Este módulo reúne toda mi práctica y evolución en **JavaScript**, desde la lógica fundamental hasta la programación orientada a objetos y la asincronía.  
Cada sección está pensada como una etapa de aprendizaje progresiva, con ejercicios revisados y proyectos prácticos para consolidar los conceptos.

---

## 📁 Estructura General

### 01 - Fundamentals
Conceptos base del lenguaje y pensamiento lógico en programación.
- **console/** → uso del objeto `console` para debugging.
- **conditionals/** → estructuras `if`, `else`, `switch`, operadores lógicos y ternarios.
- **loops/** → bucles `for`, `while`, `for...of`, `for...in`.
- **arrays/** → manipulación con métodos (`map`, `filter`, `reduce`, etc.).
- **functions/** → funciones declaradas, expresadas y flecha.
- **objects/** → creación, acceso y manipulación de objetos.
- **utils/** → snippets y funciones auxiliares reutilizables.
- **cookies/** → manejo básico de almacenamiento en cookies.
- **fetch/** → introducción a la obtención de datos con `fetch()`.

---

### 02 - DOM
Manipulación directa del documento HTML.
- **selectors/** → selección de elementos con `querySelector`, `getElementById`, etc.
- **events/** → manejo de eventos (`click`, `input`, `submit`, etc.).
- **manipulation/** → creación, eliminación y modificación dinámica de nodos.
- **projects/** → mini proyectos interactivos aplicando los conceptos anteriores.

---

### 03 - OOP
Fundamentos de la Programación Orientada a Objetos en JavaScript.
- **classes/** → definición y uso de clases con `constructor`.
- **inheritance/** → herencia entre clases y sobreescritura de métodos.
- **methods/** → métodos de instancia y estáticos.
- **projects/** → proyectos que simulan sistemas reales usando POO.

---

### 04 - Async
Lógica asincrónica y comunicación con APIs.
- **promises/** → creación y manejo de promesas.
- **async-await/** → flujo asíncrono moderno.
- **fetch/** → consumo de APIs y manejo de errores.

---

### 05 - Projects
Integración de todo lo anterior en distintos niveles:
- **mini/** → ejercicios y proyectos pequeños.
- **mid/** → proyectos medianos con lógica aplicada.
- **advanced/** → proyectos grandes y estructurados.

---

## 💡 Buenas Prácticas

- Todo el código está escrito siguiendo el **estilo modular y escalable**.  
- Se usa **camelCase** para variables y funciones, y nombres claros para carpetas y archivos.  
- El enfoque principal está en **razonamiento lógico**, no solo sintaxis.  
- Cada subcarpeta contiene ejercicios **autoexplicativos y comentados**.  
- Se prioriza la **legibilidad** por sobre la “cleverness”.

---

## 📈 Objetivo

Dominar la base técnica y mental de JavaScript para poder construir proyectos profesionales en React, manejar datos dinámicos, estructurar código limpio y comprender patrones de diseño modernos.

---

> “La sintaxis se memoriza. La lógica se entrena.”
