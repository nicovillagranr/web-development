# Practica: Theme + Cart Context

## Objetivo
Practicar Context API para estado global y acciones compartidas.

## Run

```bash
npm install
npm run dev
```

## Ejercicios sugeridos

1. Agrega un contexto de usuario con login fake.
2. Divide el carrito en multiples providers por dominio.
3. Agrega tests a reducers del carrito.
