# Practica: Focus Sessions (Hooks)

## Objetivo
Practicar useState, useEffect, useMemo, useRef y custom hooks.

## Run

```bash
npm install
npm run dev
```

## Ejercicios sugeridos

1. Agrega una pausa corta automatica cada dos sesiones.
2. Permite editar una sesion guardada.
3. Agrega estadisticas por semana.
