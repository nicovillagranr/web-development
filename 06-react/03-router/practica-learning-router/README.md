# Practica: Learning Router Lab

## Objetivo
Practicar React Router con rutas, layout compartido, rutas dinamicas y pagina 404.

## Run

```bash
npm install
npm run dev
```

## Ejercicios sugeridos

1. Agrega una ruta protegida con auth fake.
2. Crea una pagina de perfil con tabs (/perfil/:tab).
3. Agrega breadcrumbs para rutas anidadas.
