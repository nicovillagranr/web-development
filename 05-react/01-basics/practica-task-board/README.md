# Practica: Task Board (React Basics)

## Objetivo
Practicar componentes funcionales, props, estado local y eventos.

## Run

```bash
npm install
npm run dev
```

## Ejercicios sugeridos

1. Agrega una prioridad "Urgente" con color propio.
2. Muestra una barra de progreso con tareas completadas.
3. Ordena tareas por fecha de creacion.
