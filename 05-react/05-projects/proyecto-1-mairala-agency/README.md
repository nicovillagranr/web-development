# Proyecto 2: Mairala Agency (Landing React)

Landing page modular para practicar componentes y estado en interfaces comerciales.

## Stack

- React + Vite
- CSS puro

## Funcionalidades

- Hero y secciones semanticas de servicios.
- Selector interactivo de servicio destacado.
- Testimonios con navegacion siguiente/anterior.
- FAQ con acordeon simple.

## Run

```bash
npm install
npm run dev
```

## Retos sugeridos

1. Agregar formulario real con validacion.
2. Integrar animaciones por seccion.
3. Separar secciones en componentes individuales.
