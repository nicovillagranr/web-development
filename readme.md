# Web Development Roadmap

Este repositorio documenta mi ruta completa de aprendizaje como Desarrollador Front-End, desde las bases hasta la creación de proyectos en React.

## Estructura
- **01-html-basics/** → Ejercicios y mini proyectos para comprender la estructura del DOM y semántica.
- **02-css-layouts/** → Estilos, posicionamiento, responsive design y animaciones.
- **03-javascript-logic/** → Lógica, POO, manejo del DOM, APIs y proyectos integradores.
- **04-react-projects/** → Componentes, props, hooks y proyectos escalables.

## Objetivo
Mostrar mi progreso y madurez técnica a lo largo del tiempo, enfocándome en buenas prácticas, arquitectura limpia y documentación.

## Tecnologías
HTML5 · CSS3 · JavaScript (ES6+) · React · Git · GitHub
