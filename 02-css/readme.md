# CSS Styling

Este módulo cubre mi aprendizaje completo en maquetación y estilos web. Incluye desde fundamentos con CSS puro hasta el uso de frameworks modernos como **Bootstrap** y **Tailwind**, junto con una sección práctica donde replico sitios ficticios a partir de templates en formato JPG.

---

## 🧩 Estructura
1. **Fundamentals:** ejercicios de selectores, box model, display, flexbox, grid, animaciones y transiciones.  
2. **Frameworks:** proyectos prácticos con **Bootstrap** y **Tailwind CSS**, aplicando componentes y principios de diseño responsivo.  
3. **Templates:** maquetación de sitios reales basada en imágenes de referencia (templates JPG), priorizando fidelidad visual y escalabilidad.

---

## 🧱 Metodología
Para mantener consistencia y claridad en la estructura del código, utilizo el protocolo **BEM (Block Element Modifier)** en la escritura de clases CSS.  
Esto permite una organización más predecible y escalable del código, facilitando la lectura y el mantenimiento de cada proyecto.

Ejemplo:
```css
.header__nav--active {
  background-color: var(--primary);
