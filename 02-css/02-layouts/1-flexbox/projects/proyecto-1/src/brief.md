// Objetivo:
// Construir un layout completo usando Flexbox de forma
// estructurada, escalable y sin parches. Esto es base
// para cualquier dashboard real.

// ----------------------------------------------------------
//  ESTRUCTURA QUE DEBES CREAR
// ----------------------------------------------------------
// 1. Header:
//    - Ubicado arriba.
//    - Elementos alineados horizontalmente:
//      logo a la izquierda, navegación al centro,
//      acciones de usuario a la derecha.

// 2. Sidebar:
//    - A la izquierda.
//    - Menú vertical con ítems alineados y espaciados
//      correctamente usando flex-direction: column.

// 3. Contenido principal:
//    - Zona para tarjetas.
//    - Las tarjetas deben comportarse como un grid flexible
//      usando únicamente:
//        - flex-wrap
//        - flex-basis
//        - grow/shrink según corresponda

// 4. Footer:
//    - Alineado horizontalmente con Flexbox.
//    - Debe mantenerse abajo sin usar position absolute.

// ----------------------------------------------------------
//  REGLAS Y RESTRICCIONES
// ----------------------------------------------------------
// 1. Todo el layout se arma con Flexbox.
// 2. Prohibido usar Grid.
// 3. Prohibido usar position absolute para “arreglar”.
// 4. Debes usar intencionalmente:
//    - justify-content
//    - align-items
//    - flex-direction
//    - flex-wrap
//    - flex-grow / flex-shrink
//    - gap
// 5. La página debe ocupar el alto completo.

// ----------------------------------------------------------
//  HITOS A VALIDAR
// ----------------------------------------------------------
// 1. Header con alineación limpia y consistente.
// 2. Sidebar vertical sin quiebres raros.
// 3. Tarjetas que se reacomodan fluidamente al cambiar viewport.
// 4. Ningún uso innecesario de margins gigantes para “empujar”.
// 5. Código ordenado y entendible.
// 6. Version final sin comportamientos erráticos.
