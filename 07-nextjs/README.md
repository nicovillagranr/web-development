# Next.js Learning Module

Modulo orientado al aprendizaje progresivo de Next.js con App Router.

## Estructura

- `00-fundamentals/`: base conceptual, App Router, estructura de proyecto y convenciones.
- `01-routing/`: rutas, layouts, grupos de rutas, params y middleware.
- `02-rendering/`: SSR, SSG, ISR, Server Components y Client Components.
- `03-data-fetching/`: Server Actions, fetch, cache y revalidacion.
- `04-projects/`: proyectos completos para consolidar lo aprendido.
- `05-cheatsheets/`: referencia rapida y troubleshooting.

## Estado actual

- Modulo recien creado. Pendiente de contenido.

## Objetivo

Dominar Next.js desde los fundamentos hasta patrones avanzados de rendering y data fetching, construyendo proyectos reales.

## Indice recomendado de estudio

1. `00-fundamentals/`
2. `01-routing/`
3. `02-rendering/`
4. `03-data-fetching/`
5. `04-projects/`
6. `05-cheatsheets/`
