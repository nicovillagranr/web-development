# 02-layouts

Bloque de dominio practico de maquetacion CSS.

## Estructura

- `1-flexbox/`: teoria y patrones de flexbox.
- `2-grid/`: teoria y patrones de grid.
- `3-responsive/`: enfoque mobile first y adaptacion por breakpoints.
- `4-projects/`: proyectos aplicados en React + CSS.

## Criterio de dominio

- escoger entre flex y grid segun problema real
- construir layouts responsive sin hacks
- mantener estructura de estilos legible y reusable
- validar consistencia visual en distintos anchos

## Checklist por proyecto

- [ ] layout estable en mobile y desktop
- [ ] uso consciente de variables y espaciado
- [ ] componentes aislados por responsabilidad
- [ ] estilos sin reglas duplicadas o ambiguas
