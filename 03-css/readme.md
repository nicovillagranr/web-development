# CSS Module

Este modulo cubre maquetacion y estilos web desde base hasta proyectos aplicados.

## Estructura real

- `00-assets/`: recursos comunes (fuentes, iconos, etc.).
- `01-architecture/`: capas de aprendizaje y documentacion BEM.
- `02-layouts/`: flex, grid, responsive y proyectos de maquetacion.
- `03-frameworks/`: practica con framework CSS.
- `04-templates/`: maquetacion basada en referencias visuales.

## Estado actual

- En `03-frameworks/` la practica activa es con `tailwind/`.
- No hay carpeta activa de Bootstrap en esta estructura.

## Metodologia

- convencion de nombres consistente
- enfoque modular
- prioridad en legibilidad y escalabilidad
