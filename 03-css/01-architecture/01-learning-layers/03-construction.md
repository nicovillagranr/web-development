# Layer 03: Construction

## Objetivo

Construir interfaces por bloques claros y desacoplados.

## Estrategia

- dividir UI por secciones
- encapsular componentes
- separar layout global de estilo interno
- limitar selectores anidados profundos

## Practica minima

1. Maquetar una landing de 4 secciones.
2. Crear componente card reutilizable.
3. Extraer reglas comunes a utilities o tokens.
4. Medir si puedes mover un componente sin romper otros.

## Checklist

- [ ] componente reutilizable sin dependencia de contexto rigido
- [ ] layout y contenido desacoplados
- [ ] selectores simples y mantenibles
