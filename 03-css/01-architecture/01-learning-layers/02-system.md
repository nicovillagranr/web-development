# Layer 02: System

## Objetivo

Pasar de estilos sueltos a un sistema consistente.

## Componentes del sistema

- tokens: color, tipografia, espaciado, sombras
- convencion de nombres
- capas de estilos (`reset`, `base`, `layout`, `components`, `utilities`)
- estados (`hover`, `focus`, `active`, `disabled`)

## Practica minima

1. Definir variables en `:root`.
2. Construir clases base reutilizables.
3. Evitar valores hardcodeados repetidos.
4. Probar consistencia entre al menos 3 componentes.

## Checklist

- [ ] mismo token para mismo rol visual
- [ ] nomenclatura predecible
- [ ] sin reglas duplicadas para resolver el mismo caso
