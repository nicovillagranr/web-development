# 1 - Bootstrap

Aunque no hay proyecto completo en Bootstrap, esta seccion deja evidencia tecnica de dominio.

## Competencias demostrables

- Grid system (`container`, `row`, `col-*`)
- Breakpoints responsivos (`sm`, `md`, `lg`, `xl`)
- Utility classes (spacing, display, flex, text)
- Componentes base (navbar, card, button, alert)
- Integracion por CDN y estructura HTML limpia

## Evidencia

Revisa los ejemplos en `examples/`:

- `01-grid-layout.html`
- `02-components-ui.html`

## Cuándo usar Bootstrap

- MVPs rapidos
- dashboards internos
- prototipos con tiempo limitado

## Cuándo preferir Tailwind

- sistemas visuales custom
- mayor control del design token
- composicion utilitaria a medida
