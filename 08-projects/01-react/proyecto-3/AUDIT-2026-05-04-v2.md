### 🔴 ALTO: Archivos Muertos (100+ TTF)

**Ubicación:** `src/assets/fonts/`

**Problema:** Las fuentes Inter y JetBrains Mono están en el repositorio pero nunca se cargan (no están importadas en ningún CSS). Los 100+ archivos `.ttf` inflan el repo sin usar.

**Impacto:** Repo innecesariamente pesado, confusión en el futuro.

**Archivos muertos:**
- `inter/` — 3+ pesos de Inter
- `jetbrains-mono/` — 6+ pesos de JetBrains
- `poppins/` — Solo se usa el peso 400 y 700, pero están los otros pesos (100, 200, 300, 500, 600, 800, 900)

**Acción requerida:** Eliminar directorios `inter/` y `jetbrains-mono/`. Mantener solo los pesos usados de Poppins.

### 🟡 MEDIO: Formato de Fuentes (TTF vs WOFF2)

**Ubicación:** `src/assets/fonts/poppins/`

**Problema:** Las fuentes están en `.ttf` en lugar de `.woff2`. WOFF2 comprime un 30-40% mejor.

**Impacto:** Tamaño de fuentes innecesariamente grande (~15-20 KB por fuente).

**Acción requerida:** Convertir Poppins a WOFF2 (herramienta online o local)

### 🟡 MEDIO: setTimeout sin Cleanup

**Ubicación:** `src/Components/04-Portfolio/Portfolio.jsx` línea 55-57

**Problema:**
```jsx
const handleDemoClick = () => {
    setShowDemoMessage(true)
    setTimeout(() => setShowDemoMessage(false), 3000)  // ❌ Sin cleanup
}
```

Si el componente se desmonta antes de 3 segundos, intenta actualizar estado en componente unmounted.

**Acción requerida:** Usar `useEffect` con cleanup:
```jsx
useEffect(() => {
    if (!showDemoMessage) return
    const id = setTimeout(() => setShowDemoMessage(false), 3000)
    return () => clearTimeout(id)
}, [showDemoMessage])
```

### 🟡 MEDIO: Accesibilidad — Iconos sin aria-hidden

**Ubicación:** Múltiples archivos

**Problema:** Los iconos `<FaHome>`, `<FaUser>`, `<FaCalendar>`, `<FaPhone>`, `<FaMapMarkerAlt>` no tienen `aria-hidden="true"`. Los lectores de pantalla anuncian elementos vacíos innecesariamente.

**Archivos afectados:**
- `LogoSection.jsx` — `<FaHome>`
- `ContactInfo.jsx` — `<FaMapMarkerAlt>`, `<FaPhone>`
- `News.jsx` — `<FaUser>`, `<FaCalendar>`
- `Footer.jsx` — `<FaHome>`

**Impacto:** Experiencia de accesibilidad degradada pero no crítica (A11y en Lighthouse sigue en 96).

**Acción requerida:** Agregar `aria-hidden="true"` a todos los iconos decorativos

---

### 🟡 MEDIO: Accesibilidad — Botones sin aria-label contextual

**Ubicación:** `src/Components/04-Portfolio/Portfolio.jsx` línea 78-93

**Problema:** Los botones "View Demo" y "Project Details" no tienen `aria-label` con el contexto del proyecto:
```jsx
// ❌ Incorrecto
<button>View Demo</button>
<button>Project Details</button>

// ✅ Correcto
<button aria-label={`View Demo: ${title}`}>View Demo</button>
<button aria-label={`Project Details: ${title}`}>Project Details</button>
```

**Impacto:** Usuario de lector de pantalla no sabe a qué proyecto se refiere el botón.

### 🟡 BAJO: Portfolio Overlay no visible en Focus

**Ubicación:** `src/Components/04-Portfolio/Portfolio.jsx` línea 73

**Problema:**
```jsx
// Solo visible en hover (desktop) u opacity siempre 100 (mobile)
className="... sm:opacity-0 sm:group-hover:opacity-100"
```

Usuario de teclado en desktop llega al botón pero el overlay está invisible. Debería:
```jsx
className="... sm:opacity-0 sm:group-hover:opacity-100 sm:group-focus-within:opacity-100"
```
