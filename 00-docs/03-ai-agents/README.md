# From Chat to Cognitive System

Presentación **"De Chat a Sistema Cognitivo"** de Gentleman Programming, descargada como
material de aprendizaje sobre agentes de IA y mejores prácticas para usar Claude.

## Origen

- Repo: https://github.com/Gentleman-Programming/from-chat-to-cognitive-system
- Commit descargado: `ecc9a5c40d2ed291e94d0555ea47bfe5d69fc1da` (rama `main`)
- Fecha de descarga: 2026-05-02

## Cómo abrir

Doble click en `index.html` o desde PowerShell:

```powershell
start C:\web-development\00-docs\03-ai-agents\index.html
```

Requiere conexión a internet la primera vez para cargar las fuentes Google
(Space Grotesk, Source Serif 4). El resto (CSS, JS, imágenes) está local en `assets/`.

## Contenido

40 slides organizados en 10 módulos:

1. IA Generativa
2. Context Window
3. Chat vs Agente
4. SDD — Specification-Driven Development
5. Engram — memoria persistente
6. Skills modulares
7. Orquestación de agentes
8. Patrones de uso
9. Casos prácticos
10. Cierre y recursos
