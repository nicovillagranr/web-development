# Apuntes: La Evolución del Frontend (1990-Presente)

## 1. Primeros Pasos (1990-1995)
Contexto: La web estaba en fase inicial (pañales).
Tecnologías clave: HTML estático, CGI (Common Gateway Interface).
Prácticas: Generación de páginas en el servidor, sin interacción dinámica. El código de lógica y presentación estaba mezclado, dificultando el mantenimiento.

## 2. La era de CSS y JavaScript (1995-2000)
Tecnologías clave: CSS, JavaScript, Flash.
Prácticas: Aparición de estilos en línea y uso masivo de Flash para interactividad. El principal reto era el rendimiento en hardware limitado.

## 3. Era de Frameworks y librerías (2000-2010)
Tecnologías clave: jQuery, Backbone, AngularJS, npm.
Hitos: 
- Revolución de AJAX y nacimiento de las SPAs (Single Page Applications)
- Aparición de npm — Gestión de dependencias que transformó el ecosistema
- Se comienza a desplazar la lógica hacia el cliente

## 4. Modularización, Bundlers y Mobile-First (2010-2015)
Tecnologías clave: Webpack, Gulp, Babel, Bootstrap, Responsive Design.
Contexto: 
- La complejidad de las aplicaciones demandaba herramientas para manejar dependencias y transpilación para navegadores antiguos
- Explosión del móvil (smartphones): Necesidad de Responsive Design y Mobile-First como paradigma
- Package managers mejorados: Yarn surge como alternativa a npm

## 5. Metaframeworks, SSR y TypeScript (2015-2020)
Tecnologías clave: React, Angular 2+, Vue, Next.js, Nuxt, TypeScript, Testing (Jest, Vitest), CSS-in-JS (Styled Components, Emotion), CSS Modules.
Cambio de paradigma: 
- Retorno inteligente al Server-Side Rendering (SSR) y renderizado híbrido para mejorar el rendimiento y SEO
- **TypeScript** adoption masiva — Tipado estático revoluciona el desarrollo frontend
- **Testing se vuelve crítico** — Jest, Testing Library establecen estándares en testing
- **CSS-in-JS / CSS Modules** — Nuevos paradigmas para scoping de estilos
- Combinación de componentes con eficiencia del servidor

## 6. El Presente y Futuro (2020+)
Tendencias actuales:
- **Minimización de JS en cliente**: Astro (Astro Islands), Remix
- **Resumability**: Quick para cargas instantáneas
- **React Server Components (RSC)** — Cambio paradigmático: computación híbrida cliente-servidor
- **Tooling bajo nivel**: Herramientas escritas en Rust (SWC, Turbopack) o Go (ESBuild)
- **Vite**: Revoluciona el developer experience con bundling ultra-rápido
- **Edge Computing & Serverless**: Vercel, Netlify, Cloudflare Workers — Ejecución distribuida de código
- **pnpm**: Mejora drástica en gestión de dependencias vs npm/Yarn
- **Integración de IA**: GitHub Copilot, Gemini, Claude para acelerar desarrollo

Nota: Herramientas como VIM han persistido como una constante en el flujo de trabajo del desarrollador a lo largo de estas décadas.
