# Frontend Learning

Este repositorio documenta una ruta real de aprendizaje Front-End con foco en:

- fundamentos tecnicos
- practica progresiva
- documentacion de decisiones
- evolucion hacia portfolio profesional

## Estructura real del repositorio

- `00-docs/`: vision general, assets de referencia y documentos de soporte.
- `01-git/`: fundamentos de Git, commits, branching, GitHub y cheatsheets.
- `02-html/`: modulo de HTML con introduccion y 25 proyectos progresivos.
- `03-css/`: arquitectura CSS, layouts, framework (Tailwind) y templates.
- `04-javascript/`: fundamentos, DOM, POO, async, librerias y proyectos.
- `05-react/`: ruta React por etapas mas proyectos aplicados.
- `06-projects/`: espacio para proyectos integradores (en construccion).
- `07-playground/`: experimentos, pruebas rapidas e ideas.
- `config/`: archivos de configuracion compartidos.
- `root/`: documentacion legacy previa a la normalizacion actual.

## Principios de trabajo

- Semantica y accesibilidad primero.
- Complejidad progresiva, no accidental.
- Decisiones tecnicas documentadas.
- Enfoque en claridad y mantenibilidad.
- Aprendizaje validado con implementacion real.
