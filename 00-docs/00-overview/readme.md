# Frontend Learning

Este repositorio documenta mi formación y evolución como desarrollador Front-End, con un enfoque progresivo, estructurado y orientado al mundo profesional.

El objetivo de este repositorio es servir como fuente de verdad de mi proceso de aprendizaje, centralizando decisiones técnicas, estándares, proyectos y retrospectivas. Está diseñado para ofrecer orden, niveles de complejidad claros y una progresión escalable, de modo que cualquier etapa de mi carrera pueda ser entendida en contexto.

La prioridad no es acumular proyectos, sino desarrollar criterio técnico, consistencia y una base sólida para el primer rol profesional.

---

## Cómo está organizado este repositorio

La estructura del repositorio responde a una separación clara entre **documentación**, **fundamentos**, **experimentación** y **ejecución práctica**.

- **00-docs**  
  Contiene la documentación central del repositorio. Define estándares, decisiones técnicas, principios de arquitectura y retrospectivas.  
  Esta carpeta actúa como referencia estable y guía para todo el resto del contenido.

- **01-html-basics**  
  Proyectos progresivos enfocados en HTML semántico y accesible. Cada sección incrementa la complejidad de forma controlada, desde estructuras básicas hasta documentos completos.

- **02-css-layouts**  
  Práctica específica de layouts, responsive design y técnicas modernas de CSS. El foco está en comprender el comportamiento del layout, no en replicar diseños visuales.

- **03-javascript-logic**  
  Ejercicios y fundamentos de lógica en JavaScript, organizados por conceptos. Se prioriza el razonamiento, la claridad y la resolución de problemas por sobre la sintaxis avanzada.

- **03-playground**  
  Espacio de experimentación. Contiene pruebas, spikes técnicos e ideas descartadas. No representa código estable ni decisiones definitivas.

- **04-react-projects**  
  Proyectos y ejercicios enfocados en React, organizados por niveles: fundamentos, estado, routing, arquitectura y performance.

- **05-projects**  
  Proyectos aplicados. Incluye un proyecto principal que evoluciona por versiones y mini-proyectos específicos para consolidar conceptos.

- **config**  
  Configuración base del repositorio y convenciones compartidas.

---

## Principios de trabajo

Este repositorio se rige por los siguientes principios:

- La semántica y la accesibilidad son prioritarias.
- La complejidad se introduce de forma progresiva.
- Las decisiones técnicas se documentan.
- La optimización se aplica cuando aporta valor real.
- El aprendizaje se valida construyendo, no acumulando teoría.

---

## Evolución y mantenimiento

El repositorio está pensado para evolucionar en el tiempo:

- La documentación en **00-docs** cambia poco y de forma intencional.
- Los proyectos y ejercicios pueden iterarse, refactorizarse o reemplazarse.
- El playground no tiene garantías de estabilidad.

El estado actual del repositorio refleja el punto presente de la formación, no una versión final cerrada.

---

## Qué no es este repositorio

- No es un curso paso a paso.
- No es una colección de snippets.
- No sigue modas sin justificación técnica.
- No prioriza frameworks por encima de fundamentos.

---

## Estado actual

El repositorio se encuentra en una fase de consolidación de fundamentos y construcción progresiva de proyectos orientados a un primer rol profesional como desarrollador Front-End.
