# HTML Projects Index

Esta carpeta contiene 25 proyectos progresivos de HTML.

## Progresion

- 01-05: estructura base y semantica textual
- 06-10: listas, tablas y organizacion de contenido
- 11-16: enlaces, rutas, imagenes y multimedia
- 17-20: layout semantico y navegacion accesible
- 21-25: formularios y produccion accesible

## Criterio de evaluacion por proyecto

Cada proyecto deberia validar:

- semantica correcta
- orden logico del contenido
- etiquetas adecuadas para el tipo de informacion
- accesibilidad base (labels, alt, estructura)

## Nota

Las subcarpetas `assets/` vacias se mantienen como placeholders para recursos cuando un proyecto los necesita.
