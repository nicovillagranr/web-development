# HTML Document Head

## Objetivo
Comprender la estructura correcta del documento HTML y el uso del `<head>`.

## Conceptos trabajados
- DOCTYPE
- html lang
- meta charset
- meta viewport
- meta description
- title
- favicon

## Enfoque
Documento mínimo, válido y orientado a producción.

## Notas
El `<body>` se mantiene simple para no distraer del objetivo.
